## ⚙️ Getting Started & Installation

### Prerequisites
- Flutter SDK 3.x
- Dart 3.x
- Android Studio / Xcode

### Installation Steps

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/ahmedfawzyjr/todo-app.git
   cd todo-app
   ```

2. **Install Dependencies**:
   ```bash
   flutter pub get
   ```

3. **Configure Environment Variables**:
   ```bash
   cp .env.example .env
   ```

4. **Run the Application**:
   ```bash
   flutter run
   ```
